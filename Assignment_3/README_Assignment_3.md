# CS 6233: Introduction to Operating Systems - Assignment 3

**1. Compiling the Module**
Use the provided `Makefile` to compile the `lab3.c` source code into a kernel object (`lab3.ko`):
```bash
make
```

**2. Clearing the Kernel Log**
Clear the kernel ring buffer before inserting the module:
```bash
sudo dmesg -C
```

**3. Inserting the Module**
Load the compiled module into the kernel:
```bash
sudo insmod lab3.ko
```

**4. Removing the Module**
Trigger the exit function (You need to wait a bit to enter this cmd, but by the time you copy and paste this into the CLI, it should be good enough):
```bash
sudo rmmod lab3
```

**5. Clearing the Terminal (Optional)**
I like the CLI to be neat:
```bash
clear
```

**6. Viewing the Results**
Print the kernel ring buffer to view the debug messages generated by the module:
```bash
sudo dmesg
```
